# Grape-Leaf-Disease-Detection-Using-Cnn

This project uses machine learning to detect diseases in grape leaves based on images. The model is trained using a CNN and can predict different diseases.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kalyanAVT/Grape-Leaf-Disease-Detection-Using-Cnn.git
   cd 
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Train the model by running `notebooks/CNN_leaf_disease_detection_model.ipynb`. OR u can use other model notebooks as per your convinient.
2. For prediction, use `final_predict.py` or run the Streamlit app with:
   ```bash
   streamlit run app.py
   ```
